# Printer Issues

## Symptoms

- Printer offline.
- Print jobs stuck.
- No output generated.

## Troubleshooting Steps

1. Verify printer power.
2. Check printer connectivity.
3. Clear print queue.
4. Restart print spooler.
5. Reinstall printer driver.

## Escalation Criteria

Escalate if printer remains unavailable after driver reinstall.
