# Password Reset Issues

## Symptoms

- User forgot password.
- Password expired.
- Account locked.

## Troubleshooting Steps

1. Use self-service password reset.
2. Verify MFA challenge.
3. Unlock account.
4. Wait 15 minutes after password change.
5. Re-login to applications.

## Escalation Criteria

Escalate if account remains locked after password reset.
