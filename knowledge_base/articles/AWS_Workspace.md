# AWS Workspace Issues

## Symptoms

- AWS Workspace not launching.
- Black screen after login.
- Connection timeout.

## Troubleshooting Steps

1. Verify internet connection.
2. Restart AWS Workspace client.
3. Check AWS Workspace registration code.
4. Reinstall AWS Workspace application.
5. Verify account permissions.

## Escalation Criteria

Escalate if connection still fails after client reinstall.
