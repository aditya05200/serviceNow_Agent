# Laptop Performance Issues

## Symptoms

- Slow startup.
- High CPU usage.
- Applications freeze.

## Troubleshooting Steps

1. Restart system.
2. Close unnecessary applications.
3. Check Task Manager.
4. Run disk cleanup.
5. Verify available storage.
6. Run antivirus scan.

## Escalation Criteria

Escalate if performance remains poor after reboot and cleanup.
