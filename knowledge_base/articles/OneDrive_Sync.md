# OneDrive Sync Issues

## Symptoms

- Files not syncing.
- Sync paused.
- Missing cloud files.

## Troubleshooting Steps

1. Verify internet access.
2. Resume OneDrive sync.
3. Sign out and sign in.
4. Restart OneDrive.
5. Check storage limits.

## Escalation Criteria

Escalate if synchronization remains stuck for more than one hour.
