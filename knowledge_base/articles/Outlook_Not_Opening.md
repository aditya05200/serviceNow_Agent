# Outlook Not Opening

## Symptoms

- Outlook hangs on startup.
- Outlook crashes after opening.
- Outlook remains on loading screen.

## Troubleshooting Steps

1. Start Outlook in Safe Mode.
2. Disable Outlook add-ins.
3. Create a new Outlook profile.
4. Repair Microsoft Office.
5. Check mailbox size.

## Escalation Criteria

Escalate if Outlook cannot be opened after profile recreation.
