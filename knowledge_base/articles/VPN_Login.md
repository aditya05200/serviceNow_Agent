# VPN Login Issues

## Symptoms

- VPN connection fails
- Authentication error
- Connection timeout
- MFA verification failure

## Troubleshooting Steps

1. Verify internet connectivity.
2. Confirm VPN credentials are correct.
3. Reset VPN profile.
4. Reinstall VPN client.
5. Verify MFA is enrolled and active.
6. Restart the system.

## Escalation Criteria

Escalate if all troubleshooting steps fail.
